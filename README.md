# SmartHire – AI Interview Assistance (Final Year Project)

## 🚀 Overview
SmartHire is an AI‑powered interview assistance platform designed to help candidates prepare for job interviews effectively. It leverages generative AI and data analytics to simulate real interview scenarios, provide instant feedback, and guide users toward improvement.

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** SQL / MongoDB  
- **AI Integration:** Generative AI APIs, NLP models  
- **Data Visualization:** Power BI / Tableau  

## 📊 Features
- AI‑driven interview question generation  
- Real‑time candidate response analysis  
- Personalized feedback and scoring  
- Dashboard with performance tracking  
- Resume upload and evaluation  
- User‑friendly interface with responsive design
